# 🎬 Amazon Prime Clone

This project is a simple Amazon Prime Video inspired website that I built to improve my frontend development skills. My goal was to recreate a streaming platform interface while learning HTML, CSS, JavaScript, and Node.js.

---

## ✨ Features

- Responsive user interface
- Hero banner
- Movie categories
- Login & Signup modal
- Search functionality
- Smooth animations
- Clean design

---

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Git & GitHub

## 🚀 How to Run

```bash
git clone https://github.com/fizaaly/Amazonprimeproject.git

cd Amazonprimeproject

npm install

npm start
```
